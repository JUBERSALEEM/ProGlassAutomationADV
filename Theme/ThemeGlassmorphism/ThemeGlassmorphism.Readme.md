# Glassmorphism — sixth registered theme (Phase 01 / step1)

Native WPF. Studio canvas (`GlassCanvasBrush`) plus translucent frost faces, luminance hairline, restrained lift, ReduceTransparency solid fallback.

Not Liquid Glass (no sky, no sun/moon, no thin specular veil). Not Fluent mica/acrylic. No BlurEffect — WPF blur is not backdrop-filter. No extras studio.

Owner accepted Light Home and Dark Home (Glassmorphism / Pill, Theme plate). Formal V1 for this theme. D01 Liquid visual remains BLOCKED and is a different engine.
