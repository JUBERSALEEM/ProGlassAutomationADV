## Where to find more

- **In the app** — **About → License**, **About → Recent crash reports**, **Settings → Data → Database Health**, **Logs & Activity**.
- **On disk** — `%AppData%\ProGlassAutomation\` is the canonical data folder. See `INSTALL.md` for the full layout.
- **From the vendor** — your vendor ships these docs alongside the Setup.exe. The vendor's support email is in the Setup's welcome dialog and in the About page footer.

## Conventions used in these documents

- **Bold** is for buttons, menu items, and short important terms.
- `Code font` is for file paths, code, and error IDs.
- "The app" means ProGlass Automation, the customer-facing binary.
- "The vendor" means the company that issued your licence.
- "The developer" means the original author of the codebase (different from the vendor in some reseller scenarios).
