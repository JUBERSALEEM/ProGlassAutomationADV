# Shell mockups

Measured at 1440×900. Colors are the live indigo tokens: canvas `#F3F0FA`, surface `#FFFEFC`, line `#E2DBEF`, ink `#2C2440`, muted `#6B6078`, accent `#6546B5`, soft `#EEE8F8`.

Every label is a real navigation string. Every top-bar control already exists: menu, logo, ProGlass, SUITE, module title, search, date, time, moon, user chip, AI, Agent, activity, settings, more. Sidebar icons are the Segoe MDL2 tags already on those buttons. The drawn marks are stand-ins for those tags, not new icons.

01 is already in the top bar. The others are layout options only.
