# Installer and release audit

## What ships

- `Setup.exe`: one-click Velopack splash. Live progress strip is hidden so the rounded splash is not cut. No license page or folder picker on Setup.exe.
- MSI: Windows wizard plus generated 493×58 banner and 493×312 dialog, and welcome/readme/licence/scope/finish text. Windows still draws chrome, fonts, and buttons.
- FFmpeg and the offline GGUF model are in-app downloads. Nothing downloads until the user clicks Install.
- Images are generated by `scripts/generate-installer-art.ps1` into `installer/generated/`, which is gitignored.

## Packaging guard added this cycle

`PRODUCTION_READINESS/**` is removed from Compile, None, Content, Page, and Resource in `ProGlassAutomation.csproj`. `scripts/build-installer.ps1` deletes a leaked `PRODUCTION_READINESS` folder from the publish directory before `vpk pack`.

## UNVERIFIED

- `vpk pack` was not executed here.
- Authenticode signing was not executed.
- The Windows publish profile was not executed.
