WHY THIS READS PROFESSIONAL

1 · One language, seven modules. All 7 dashboards already consume the same Db* kit (verified in XAML) — restyle the kit once, everything follows. No view rewrites.

2 · Colour = status. Icon chips are neutral by default; red/amber appear only where work is overdue or pending. Today every tile carries a coloured chip, which dilutes the alarm.

3 · Flat + hairline. No card shadows, no glass tints on data surfaces — a 1px hairline and type hierarchy do the separating. Depth is cheaper and crisper.

4 · Type discipline. Six sizes, tabular figures, uppercase captions — nothing competing.

5 · Theme-safe. Every value is a token; Light/Dark swap at runtime exactly as today (DynamicResource).
